Separately, and only because it is the same regex: I tested whether the MARKETING pattern
misfires on portal invitations, since tender portals put "unsubscribe / manage preferences"
footers on them. It does not, and the reason is worth knowing - you match MARKETING against
Graph bodyPreview, which is ~255 characters, and the footer sits far below that. Checked
against five real portal emails: none carries a marketing phrase in the first 400 characters.
If that ever changes to a full-body match it would start eating tender invitations.
