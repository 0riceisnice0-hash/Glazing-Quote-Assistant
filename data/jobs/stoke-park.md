**Two lessons for this job.**

1. The shortfall was systematic - one pane per bay on six window types - and a systematic gap
   is usually a category the schedule deliberately excludes, not an error. Search the job
   folder for the other category before raising the alarm. `QT50932 Rev7 Louvres.pdf` and the
   IKON quote were both on file the whole time.
2. **Both alarms on this job were raised against documents that were already superseded by
   work happening where Mary cannot see it.** REQ-3 was answered by two files in the job
   folder; REQ-11 by a mailbox and an orders folder outside it. On a LIVE project the estimating
   trail is not the current record - `4. Orders\` and commercial@ are. Check those first, and
   treat a quote on file as history rather than as the position.
