BSW, 11:51, in writing:

So your 24/07 ruling stands - Sheerline 70mm cannot join Smart Wall 100mm - but THE FIX AS WRITTEN CANNOT BE BUILT. There is no Smart Wall window to move W.01, W.04 and W.05 into. That leaves three routes, and they are not equal:

  1. MOVE THE WHOLE RUN TO A SYSTEM THAT MAKES BOTH. Our own system table already
     has Smart Alitherm 600 at 100mm - the same depth as Smart Wall - and it is a
     system that does windows as well as doors. It is also the system I flagged on
     24/07 as the thermally broken alternative for the door U-value, so it solves
     two things at once. THIS IS THE QUESTION FOR BELLVIEW: can Alitherm 600
     windows couple to a Smart Wall door element at the shared 100mm, or should
     the East and West runs be Alitherm 600 throughout?
     I am not asserting a coupler exists between two Smart systems. Same depth is
     necessary, not sufficient. It needs Bellview in writing.

  2. DECOUPLE. Separate the windows from the doors with structure between them so
     nothing is joined. That is an architect's question, not a supplier's, and it
     changes the elevations.

  3. Leave it as it is and qualify it. I do not recommend this on a run where the
     coupling is what makes the elevation.

All three change the price. None of them is an adjustment to the existing document.
